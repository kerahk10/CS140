Internet

Network of computers connected to it to share information with one another. It links private, public, school, business, and government computer networks everywhere.

Web

A section of the internet where you click links to get into different pages and websites. It is also known as the World Wide Web.

How is the Internet and Web different?

The Web is a collection of information. The Internet is a physical network where you can acess this collection of information from the web.

ASCII and Unicode

ASCII is a code sytem that has computers represent letters, symbols, and numbers. Unicode is a character encoding standard made for covering all of the world's writing systems.

What is UTF-8

UTF-8, also known as 8-bit Unicode Transformation Format, is a encoding standard that uses characters to translate universal text into bianary data that computers can read.

URL

An adress for a specific web page, file, or resource on the internet. The adresss is unique and it allows your web browser where to go and how to get there.

Domain Name

An address that is readable to people and people cnan type it into a web browser to visit a website.

HTTP

Hypertext Transfer Protocol, is the set of rules used by the web to exchange data from web browsers and servers.

HTTPS

Hypertext Transfer Protocol Secure, is the encrypted version of the standard HTTP used to send data from your browser and a website.

IP Address

Internet Protocal adress, is a numerical label made for every device that can connect to a computer network, used as a digital adress that lets devices send information and also recive it back.

DNS

Translates website names into computer readable IP adresses.

W3C Reccomnedations

A web standard that developers and browsers should follow to keep the internet working well. Its an official blueprint made by the World Wide Web Consortium.

XML, XHTML, HTML, HTML5

Markup languages made to build data and web pages. XML stores, carries, and exchanges structured information. HTML creates and structures the visual layout of web pages. XHTML rewrites HTML using the rules XML follows. HTML5 Is the newest and current generation of HTML, used as a development platform.
