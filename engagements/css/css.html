  • Block tags start on a new line, while inline tags stay on the same line and only take up as much space as the text.
  • The elements make up the Box Model that structures every tag and element. Padding is the inner space, while the border is the line wrapped around that padding. Margin is the outer space that separates the element from everything else on the page.
  • CSS uses px for sizes that never change. Viewport units let you size things based on a percentage of the screen size.
