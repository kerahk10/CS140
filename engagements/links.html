1. Absolute Link: Visitor Centers

2. Explain the difference between an absolute link and a relative link. Why would you use relative links?

Absolute links contain the entire URL of where the link should go to. Absolute links are used to link wesites outside of your own web page, while relative links show part of a path already located on the current page. You would use relative links in order to easily access info from your web page.

3. Relative Link: Structural

4. List the 3 rules with relative links.

  1. Absolute paths, which is the complete web adress.
  2. Document-relative paths, linked to the current web page you view.
  3. Site-root relative paths, a path starting from the main root folder of your website.
