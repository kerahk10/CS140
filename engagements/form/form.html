Question Answers

  1. The action attribute specifies the place where the data would be sent for processing when you click the submit button.

  2. The method attribute specifies the HTTP method used to send form data to the server.

  3. A GET is used to get data from a server, while a POST is used to send data to a server to create or update a resource.

  4. a. A text box is a value text already entered into the box that the user can edit. The text disappears when the user starts typing.
    b. Textarea is a message already written in the larger text area. A placeholder is hint text that disappears when the user starts typing.
    c. Select box is an option selected when the form loads. A placeholder is a prompt telling the user to choose an option.
    d. Checkbox means the checkbox is already ticked when the form loads. Checkboxes do not have placeholders.
    e. Radio button means one of the options are already selected when the form loads, they do not have placeholders.

  5. The form controls that HTML5 added are color, date, email, month, number, range, search, tel, time, url, week, datetime-local, datalist, output, progress, meter, keygen. I used number and checkbox.
