CSS Selectors

List out the different ways to select an item.

Class, Id, universal, and element selectors.

What is the difference between an ID and a Class?

The main difference is that an ID is can only be used on one element for each page, while class can be applied to many elements.

What is the difference between a SPAN tag and a DIV tag?

The difference between the tags is that a SPAN tag stays within the paragraph while a div tag starts on a new line.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div is a general area with not much details, while header, main, and footer are elements that tell both the browser and search what kind of information lives inside them.

What are the different ways to select a color?

You can use RGB or color names to select the color you want.
